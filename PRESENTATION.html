Научный вопрос

Существует ли универсальная сигнатура фазовых переходов, общая для финансов, геологии иhousing?

Гипотеза: параметры (m, ω) из одного распределения

💡 Решение: LPPLS модель

ln(p(t)) = A + B(tc−t)^m + C(tc−t)^m · cos(ω·ln(tc−t) + φ)

7 параметров

  • tc — критическое время (когда крах)
  • m — экспонента роста (0.1–0.9)
  • ω — частота осцилляций (6–13)
  • A, B, C₁, C₂ — линейные параметры

Физический смысл

Суперэкспоненциальный рост + логопериодические осцилляции = детерминированный процесс, не случайность
